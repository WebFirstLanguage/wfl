# Archive

Retained but **inactive** material: superseded plans, completed phase reports,
old bug write-ups, security review snapshots, and legacy programs kept for
historical, evidentiary, or design value.

**Nothing in this directory is normative.** Archive content is excluded from
maintained documentation navigation; current behavior and policy come from the
root policy files, `Docs/`, the code, and the tests. Content is preserved
byte-for-byte where practical — corrections belong in `manifest.json` metadata
or a dated addendum, never silent edits.

Every file here is indexed in `manifest.json` (path, original path, source
commit, sha256, dates, kind, status, reason, `normative: false`, supersession,
related issues/PRs, security classification). The repository hygiene checker
verifies the index and checksums in CI; add or move archive content only
together with its manifest entry (see `REPOSITORY_HYGIENE.md` §7).
