## Independent review and recovery

A separate review agent examined the actual CLI, linter, layout, formatter,
diff, and atomic-write implementation. It reproduced unsafe data/API renames,
ignored configuration switches, interface indentation, and Unicode whitespace
inconsistency. Each finding has a retained regression and a corresponding fix.
A 30,000-statement source probe completed in 112 ms with lint findings.

Fixing validates source before editing and reparses the output before writing.
In-place uses a same-directory temporary file, flush/sync, and rename. Stale
checks compare bounded chunks rather than reloading a potentially growing
file. Failed preparation/publication preserves the previous contents; no-op
fixes avoid replacement. This is not an interprocess editor lock, and Unix
permission-bit preservation does not guarantee ownership/custom ACL retention
or parent-directory crash durability. Diff previews and version control remain
available for reviewing/reverting intended edits.
